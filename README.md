# DOICHEV AUTO PARTS

Trilingual (Spanish, Ukrainian and English) website for DOICHEV AUTO PARTS in Torrevieja.

## GitHub Pages

The website is a static site in the repository root. The workflow in `.github/workflows/deploy.yml` publishes the static files to GitHub Pages whenever changes reach `main`.

## Local preview

Open `dist/index.html` in a browser, or serve the `dist/` directory with any static file server.

Website developed by [Ministry of Transformation](https://ministry-transformation.github.io/).
